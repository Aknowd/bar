ここでは，audio visualizer type echo (AVt Echo)の導入方法を解説します．

AVt Echoは，任意の音声ファイルの音色を波紋として視覚的に表現することを目的としたアプリケーションです．

## 動作環境
Windows 11 Home 64 bit


1. 起動方法
以下のリンクより，フォルダをcloneするか，最新版のmainブランチよりzipファイルとしてローカル環境にダウンロードしてください．

[Audio Visualizer type ECHO](https://github.com/xxx)

フォルダを開き，Audio Visualizer type voltage.exeファイルを起動してください．

2. 主な機能
Read: 任意の音声ファイルを選択して開きます．
Play: 音声を再生します．
Tuning: 閾値を設定して，視覚表現の強度を調整します．
Record: Visualizer画面を動画ファイルとして保存します．
